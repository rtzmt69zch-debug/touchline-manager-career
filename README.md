# TOUCHLINE — 잉글랜드 감독 커리어

한국어 기반 React + Vite 축구 감독 커리어 웹게임입니다. 싱글플레이는 별도 서버 없이 로컬 브라우저 저장으로 작동합니다. 온라인 공개/비공개 리그는 Supabase 프로젝트를 연결하면 로그인, 리그 생성·참가, 초대 코드, 참가자 목록, 경기 결과 피드의 실시간 동기화를 사용할 수 있습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 Vite가 안내하는 주소를 엽니다.

## 온라인 기능 연결

1. Supabase에서 프로젝트를 생성합니다.
2. `supabase/migrations/001_init.sql` 전체를 Supabase SQL Editor에서 실행합니다.
3. 프로젝트 Settings → API에서 Project URL과 anon/public key를 복사합니다.
4. `.env.example`을 `.env`로 복사하고 다음 값을 입력합니다.

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

5. Supabase Authentication에서 이메일 로그인을 활성화하고, 개발/배포 주소를 Redirect URLs에 추가합니다.
6. 개발 서버를 재시작합니다. 배포는 Vercel/Netlify 등 정적 호스팅에 연결할 수 있습니다.

## 구현된 주요 기능

- 감독 출신 경로 4종 및 전술 철학 3종
- 감독 경력에 따라 생성되는 3~5개 구단의 감독직 제안서: 구단, 리그, 주급, 계약 기간, 보너스, 이적 예산, 구단 기대치 비교 후 선택
- 프리미어리그 20팀, 챔피언십·리그 원·리그 투·내셔널리그·내셔널리그 노스/사우스 각 24팀의 실제 구단 이름 기반 구단 풀
- 1부 38경기, 2~7단계 46경기 리그 일정 생성
- 리그 성적, 체력, 사기, 구단 신뢰도, 연패, 시즌 종료 승격·강등 처리
- FA컵/카라바오컵 경기, 컵 경기 전 선발/로테이션 선택
- 경기 3일 이내 일정 경고 및 리그·컵별 로테이션 선택
- 15·30·45·60·70·80·90분 단위 라이브 경기 진행, 득점·실점·부상·퇴장 이벤트, 하프타임·실점 직후·후반 막판 전술 및 교체 선택
- 전술 설정, 감독 능력치, 연봉·자금, 영구 아이템 및 성장 가속
- 시즌 이벤트, 감독 자격증, 시즌 기록, 리그 우승·감독상, 유럽대항전 규칙 표시
- 승격 플레이오프, 계약 만료·재계약, 라이벌전/컵 결승 패배 후 기자회견, 팬 커뮤니티 반응, 은퇴 및 유명 감독 스타일 유사도 보고서
- 싱글플레이 자동 저장(localStorage)
- Supabase 이메일 로그인, 공개/비공개 리그 생성, 공개 리그 디렉터리, 초대 코드 참가, 온라인 멤버 목록·경기 결과 피드·공유 순위표 Realtime 동기화

## 중요한 범위 안내

이 프로젝트는 독립적인 축구 커리어 시뮬레이션입니다. 실제 경기 일정, 실제 선수 데이터, 실시간 축구 결과 또는 공식 구단 라이선스 데이터를 가져오지 않습니다. 구단 이름은 게임 시작용 구단 풀로 제공되며, 시즌 일정은 게임 내에서 생성합니다.

온라인 기능은 Supabase URL/키와 SQL 마이그레이션 적용 후 활성화됩니다. 현재 온라인 버전은 계정·리그 로비·참가자·경기 결과 피드·참가자별 결과 집계 순위표를 서버와 실시간 동기화하는 MVP입니다. 각 플레이어의 경기 결과를 공유 순위표에 합산하지만, 모든 감독이 동일한 고정 대진을 동시에 치르고 AI·유저 구단이 같은 일정에서 맞붙는 완전한 서버 권한형 시즌 시뮬레이션, 온라인 이적시장, 친구 간 직접 대전은 후속 개발 범위입니다. 공개 리그 디렉터리는 공개 리그 목록과 참가 버튼을 제공합니다.
